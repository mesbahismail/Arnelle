# Demo assets

- Photography: Unsplash image URLs are recorded in `native/src/data.ts`. Local preview copies are in `public/media/`. Images are demo content, distributed under the [Unsplash License](https://unsplash.com/license), separately from the code's MIT license. Do not imply endorsement by the people depicted. Replace with your own media for a product launch.
- Illustrated SVG avatars: original procedural illustrations in `avatarSvg`, MIT licensed with this template.
- Native sample video: Big Buck Bunny, Blender Foundation, [CC BY 3.0](https://peach.blender.org/about/), hosted at the Expo sample-media CDN. This is a playback demonstration, not a live stream.
- Web sample video: Pexels video 856857, used as remote demonstration media, [Pexels License](https://www.pexels.com/license/).
- Audio: an original synthesized 30-second demo melody generated locally in `native/src/media.ts`. Track titles and artists are fictional UI data; they all preview this melody. The web preview synthesizes a short melody with Web Audio.
- Icons: Lucide (ISC) in the web preview; Ionicons (MIT) through Expo in the native app.
- Fonts: DM Sans and Manrope (SIL Open Font License) for the web preview. Native iOS uses the platform's system font.

Remote images and video need internet connectivity. The desktop preview's photographs are bundled locally. No original artwork from the supplied reference screenshots is included.
